# OTA 升级原版（改动前的存档）

这里保存的是**动手改造之前、跟着教程做出来的原始版本**。

只存了 6 个「和现在有差异」的文件，其余文件（`Library/`、`Start/`、`OLED.c`、
`usart.c` 等）没有改动，所以没有存档。

| 存档文件 | 现在的版本改了什么 |
|---|---|
| `2-IO模拟IIC驱动24C02/Hardware/iic.c` | 软件 I2C 引脚由 `PB6`/`PB7` 改到 `PB10`/`PB11` |
| `3-IO模拟SPI驱动W25Q64/Hardware/iic.c` | 同上 |
| `4-内部FLASH擦写/Hardware/iic.c` | 同上 |
| `5-规划AB分区…/Hardware/iic.c` | 同上 |
| `6-串口IAP功能/Hardware/iic.c` | 同上；并新增 5 个诊断接口（空闲电平 / 外部上拉探针 / 拉地探针 / 角色对调 / 全地址扫描）|
| `6-串口IAP功能/User/main.c` | 新增上电硬件自检 `HW_SelfTest()` 与 `AT24C02_Diag()` |

**为什么要改引脚**：本板上 OLED 模块的 GND / VCC 分别走 `PB6` / `PB7`，
那两个脚是**电源通路，不能当 GPIO 用**，所以软件 I2C 让到了 `PB10`/`PB11`。

**为什么要留这份存档**：这些文件的「改动前」状态**在 git 历史里找不到** ——
建基线提交时它们已经被改过了。留一份是为了能对照「教程给的」和「自己做的」，
也是根目录 README 里
[「这部分是跟着教程实现的 / 这部分是自己补的」](../README.md#项目结构与来源说明)
那句话的凭据。

> 对照方法：直接和仓库里同路径的文件 diff 即可。
> 改动的原因和定位过程见 [`docs/工程问题与踩坑记录.md`](../docs/工程问题与踩坑记录.md)
> 和 [`docs/AT24C02-调试记录.md`](../docs/AT24C02-调试记录.md)。
